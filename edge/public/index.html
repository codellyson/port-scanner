Port Scanner GitHub

See what's listening on your machine. Close it, or share it.

Port Scanner is a tray app and CLI for macOS, Linux and Windows. It lists every open port with the process behind it, lets you end that process in one click, and can turn a local port into a public link when you need one.

v1.0.9 · MIT · free

List

Every port, with protocol, state, process name and the path of the executable that opened it. Filter by any of them, or get JSON for scripts.

Kill

See the name and the path before you act, then end the process from the row. No process ids to look up.

Expose

Get an HTTPS link that reaches a local port. Every link carries its own key. Close the tunnel and the link stops working.

Install

Native builds for Apple silicon and Intel Macs, Linux and Windows are attached to every release. To build the CLI and dashboard yourself, you need Node 18 or newer.

git clone https://github.com/codellyson/port-scanner
cd port-scanner
npm install && npm run build
node dist/index.js web --token "$(openssl rand -hex 16)"

The app is unsigned. macOS quarantines it on first launch: right-click it and choose Open, or run xattr -dr com.apple.quarantine "/Applications/Port Scanner.app" once.
